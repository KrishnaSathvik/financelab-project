# MoneyBasis UI audit and fixes

Implemented against the pasted final UI/UX brief on September 18, 2026.

## Changes

- Homepage: a multi-tool dashboard replaces the mortgage-only hero; sections follow tools → differentiation → interactive example → learning.
- About: Calculate / Visualize / Understand product overview replaces the mortgage result.
- Visual library: separate mortgage illustration plus ten topic-specific schematic patterns. Guide visuals and empty calculator previews are contextual; illustrative figures are labeled.
- Directory: two wide housing cards and four-column groups on large screens; one bottom CTA per fully clickable card. Related cards share this treatment.
- Global navigation: the same four destinations on desktop and mobile. Footer includes all calculators, investing, retirement, and debt.
- Calculator sharing: compact header disclosure, calculator-only default, explicit opt-in to inputs, clipboard error handling, Escape dismissal. Fixed the pre-existing missing restoration of shared inputs across all ten calculators. Shared input structure is checked before restoration and is not saved to device storage.
- Mortgage: down payment replaces the duplicate payment metric. Expandable amortization has yearly/monthly views and matching CSV export. Monthly rows reconcile to yearly totals.
- Rent vs buy: equally prominent buyer and renter positions, labeled difference, and expandable crossover explanation.
- Investment: separate starting amount, subsequent contributions, growth, and years.
- Retirement: result names the retirement age; chart uses age labels and the selected income target line.
- Net worth: horizontal assets/liabilities comparison replaces the misleading combined donut. Asset composition remains available separately.
- Loan payoff: primary result is the estimated debt-free date, supported by remaining time and savings.
- Debt: payoff order remains above the chart; debt balances are stacked and the monthly payment budget is a supporting metric.
- Salary: compact selected-tax-year badge, expandable tax details, existing deduction chart retained.
- Savings: compact what-if callout; existing goal and accumulation visuals retained.
- Methodology: scrollable/wrapping calculator chips, concept icons, and separate estimate/input/formula/limitations/source sections.
- Guides: contextual visuals, category accents, sticky desktop contents and collapsible mobile contents.
- Education: 3–4 FAQs per calculator and concept grids sized to their content.
- Responsive: workspaces stack below 960px; mobile inputs use 16px text; buttons have 44px minimum targets; tables scroll inside their containers.

## Scope and limits

This pass addresses presentation, navigation, and sharing. Existing calculation tests were run, but this is not the separate comprehensive financial correctness, source verification, tax-data validation, or production-launch audit. Guide diagrams are labeled schematic patterns rather than plotted numeric examples. Browser emulation verifies layout and input font sizes; it does not establish physical iOS keyboard/zoom behavior.
